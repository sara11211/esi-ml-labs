# ESI ML Labs

Lab work from the Machine Learning course at ESI Algiers (2CSSID). In each lab, the core algorithms are implemented from scratch in Python, then tested and analysed with experiments.

## Labs

| Folder | Topic |
|---|---|
| `Lab01SD` | Logistic Regression |
| `Lab02SD` | Naive Bayes |
| `Lab03SD` | Decision Trees & Ensembles | 
| `Lab04SD` | Support Vector Machines |
| `Lab05SD` | Neural Networks |
| `Lab06SD` | Regularization & Feature Selection |

Each folder contains:
- a `.ipynb` notebook with the implementation and analysis
- a `.txt` file with the lab instructions
- a `data/` folder with the datasets

## Usage

```bash
git clone https://github.com/sara11211/esi-ml-labs.git
cd esi-ml-labs
pip install numpy pandas scikit-learn matplotlib jupyter tensorflow
jupyter notebook
```

Then open the notebook of the lab you want.
